# מודעות מצבית: אחרי הרעש

מסך טוטם אינטראקטיבי (9:16, RTL) להכשרת קציני ביטחון — סכנות לאחר רעידת אדמה.

## הרצה
פותחים את `index.html` בדפדפן (רצוי במסך מלא, F11). אין צורך בהתקנות.
פונטים (Karantina, Assistant) נטענים מ-Google Fonts — נדרש אינטרנט.

## מבנה
- `index.html` – המבנה
- `css/style.css` – עיצוב
- `js/app.js` – לוגיקה, וכן `CONFIG` ו-`SCENARIOS` (תרחישים, אזורי לחיצה וטקסטי המשוב) בראש הקובץ
- `images/` – לוגו ותמונות התרחישים

## הוספת תרחיש
מוסיפים תמונה ל-`images/` ואובייקט חדש ל-`SCENARIOS` ב-`js/app.js`.
אזורי לחיצה: `[מרכז-X%, מרכז-Y%, רוחב%, גובה%]` יחסית לתמונה.
